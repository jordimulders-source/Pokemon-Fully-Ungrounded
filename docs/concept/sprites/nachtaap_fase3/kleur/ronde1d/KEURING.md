# Keuring kleur ronde 1d (onafhankelijke keurder, 5 nov)
PASS: omlijning (0 open randen), ogen, kop/gezicht op 1×, vuist + bovenarm (cilinder), spiraal (Nazca, 1 px lucht), achterwerk, palet (15).
FAIL: romp vlekkerig (3/4 wisselend + 5-vlek), gloed als kader (rechte rand), maan leest als hoofdband, vingerscheidingen donker (handschoen/rooster), onderste voet zonder hiel, opgeheven been-aansluiting op 1× niet te zien, opgeheven been als pijp zonder knie.
Kleine reparaties 1–5 (±40 px) → ronde 1e. Voor Jordi: opgeheven been (aansluiting/knie = silhouetwijziging), anatomie healerarm (arm loopt onder de hand door), gloed als kader of handvorm.
