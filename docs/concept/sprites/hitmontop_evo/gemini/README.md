Prompt: `PROMPT.md` (variant B: hoofd + stickman). Regels: `docs/lessen/GEMINI.md`.

1. (7 nov) `ronde1.png`. Jordi: "de armverhouding is een beetje gek en de pose klopt niet helemaal". Goed: Hitmon-verhoudingen (grote kop/handen/voeten, dunne ledematen), hoofd met V, knot met witte band en kleine hoorn, geen shirt, witte broek met geel/groene strepen, geel koord met knoop, koordband om de arm, blauwe klauwvoeten, V-split.
