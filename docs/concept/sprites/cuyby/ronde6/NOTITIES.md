# Cuyby ronde 6

Kleurwissel op verzoek van Jordi (24 okt): oranje naar links (voor de kijker), zwart naar rechts, zodat het zwart aan dezelfde kant zit als bij Cuychu. Puur een indexwissel op ronde 4 (a→6, b→7, 6/7→a, 8→b, 9→14), vorm pixel voor pixel gelijk; 706 px (2 frames) van kleur veranderd.
