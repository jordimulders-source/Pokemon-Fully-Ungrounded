# Lessen: Emulatortests

Lees vóór emulatortests (mGBA, testrom.py, saves). Opgesplitst uit CLAUDE.md (23 okt); nieuwe lessen hier toevoegen.

- **Emulatortests:** de intro-savestate heeft een kapotte party (Lv0); doe `givemon` vóór een testgevecht. Zonder `setflag FLAG_SYS_POKEMON_GET` ontbreekt POKéMON in het startmenu. B in een wild gevecht zet de cursor op Run (wacht op berichten i.p.v. B te drukken). Tas: pockets wisselen met RIGHT (hold 8, ~60 frames), Key Items = 4× RIGHT. HP/status testen: direct in `gPlayerParty` schrijven (100 bytes per Pokémon; status +80, hp +86).
- **Save-offsets voor emulatortests:** de `/*0x...*/`-commentaren in `include/global.h` kloppen niet meer (expansion); laat de compiler `offsetof` berekenen (cpp + preproc + cc1, zie Makefile-flags) of lees een symbool uit `pokeemerald.map`. Bijv. `trainerRematches` = SaveBlock1 + 0x92A.
- **Wilde gevechten/transities testen:** debug Utilities > "Wild battle (map)" of in `testrom.py` het script `special Debug_StartMapWildBattle; waitstate` na een warp. Een soort forceren in een emulatortest: schrijf `gDebugForcedWildSpecies` (adres uit `pokeemerald.map`) met `e.core.memory.u16[adres] = soort`. Transitie vanaf frame 0 vastleggen: de laatste A van het debugscript met `after=0`.
- **Spelerpositie in emulatortests:** lees `gSaveBlock1Ptr` uit `pokeemerald.map` en dan `pos` (s16 x, y op offset 0); loop met een goto(x,y)-lus in plaats van een vaste toetsenreeks (scripts slikken soms een stap in).
- **Emulator-screenshots hebben een dag/nacht-tint** (`OW_ENABLE_DNS`, echte klok): roze/oranje of blauw is de tijd van de dag, geen paletbug.
- **Gehoorzaamheid in emulatortests:** de intro-savestate heeft geen badges, dus een `givemon` boven lv 10 is ongehoorzaam (doet een andere move, gaat slapen). Altijd testen met lv ≤ 10 óf eerst alle badges zetten (`setflag FLAG_BADGE01_GET` … `FLAG_BADGE08_GET`).
- **Wilde gevechten via debugscript** starten pas na de eerste knopdruk: na `debug_script` eerst A, dan ~400 frames wachten tot het actiemenu er is.
- **ROM opleveren:** heet altijd `Pokemon_Ungrounded_1.0_testfix8.gba` (Jordi 15 okt: vaste naam tot zijn testrun klaar is, anders laadt zijn .sav niet). 32 MB is te groot voor SendUserFile; zip hem (≈21 MB). Bouw eerst opnieuw na `testrom.py`.
- **Gevechten in emulatortests aansturen:** wacht niet op vaste frames maar lees `gBattlerControllerFuncs[0/2]` (adres via `arm-none-eabi-nm pokeemerald.elf`) tot het `HandleInputChooseAction` van de speler is. Spread-moves (Muddy Water) vragen een extra A (`HandleInputShowTargets`). `gBattleOutcome` 1 = gewonnen.
- **Emulatortests van menu-flows:** lees `gMain.callback2` (gMain+4) om te zien welk scherm actief is en lees de schermstatus uit een statische struct (`sCards` in `pokeemerald.elf`); reageer daarop i.p.v. vaste toetsreeksen.
- **Emulatortests van gevechten:** `gMain.callback2` heeft de thumb-bit (vergelijk met `& ~1`); zet `gBattleOutcome` vóór elk volgend gevecht op 0; een gevecht forceren: `gBattleMons[1].hp` (offset 42, struct 104 bytes) op 1.
- **Startmenu onthoudt de cursor:** na een PokéNav-bezoek in een emulatortest opent START → A de PokéNav i.p.v. het debugmenu.
- **Emulator in een verse container:** `pip install mgba` faalt op Python 3.13; `python3.11 -m pip install mgba pillow numpy` werkt. Ontbreekt `libmgba.so.0.10`: `apt-get install -y libmgba0.10t64`. Draai emulatortests en testrom.py met `python3.11`.
- **Klok in emulatortests:** `TZ` + `time.tzset()` vóór het laden van mGBA zet de dag/nacht. Pijltrappen sturen je meteen terug als je de pijlrichting indrukt.
- **Emulatortests (casino):** `gSaveBlock2Ptr` verhuist na een gevecht of warp: lees altijd opnieuw via de pointer. Structs zijn met apcs-gnu op 4 bytes uitgelijnd: neem groottes uit `nm -S`, niet met de hand. `sSpireBosses` is een aparte array naast `sSpireEncounters`.
- **Sweep vóór een release** (v1.0): scripts van de playthrough-agent (alle 718 kaarten laden, alle 1406 warp-landingen, alle Battle test-ingangen, wild per kaart) werkten goed; opnieuw maken met `testrom.py` (scripts: 1 warp, 2 setup met badges + 2× Arceus, 3 `special Debug_BattleTest_Start`) en `sBattleTestCurrent` in het geheugen zetten per ingang.
- **Savestate na een nieuwe ROM = corrupt** (Jordi's testrun 12 okt): savestates werken alleen op exact dezelfde build. Herstellen: in de `.ss0` (PNG) zit het geheugen in chunk `gbAs` (zlib), met de ROM-CRC32 op offset 8; bouw die commit na (alleen de gewijzigde bestanden terugzetten + incrementele `make`), laad met `load_raw_state` in mGBA (python3.11) met een vooraf aangemaakt flash-bestand van 128 KB `0xFF` (`autoload_save`, anders segfault tijdens het saven), save in het spel en lever de `.sav`. Raad Jordi aan in het spel te saven vóór een nieuwe ROM.
- **Save van Jordi aanpassen** (event opnieuw triggeren): .sav = 2 slots × 14 sectoren van 0x1000 (footer op 0xFF4: id, checksum, signature 0x08012025, counter); neem de slot met de hoogste counter, plak SaveBlock1 uit sector-id 1–4 (3968 bytes data per sector), pas flags (`offsetof(struct SaveBlock1, flags)` via cpp + cc1 `-mabi=apcs-gnu`) aan en herbereken per sector de checksum (u32-som over de data, `(s>>16)+s`). Controle: onveranderde sectoren houden hun checksum; daarna laden in mGBA.
- **libmgba ontbreekt soms in een verse container:** `apt-get install -y libmgba0.10` (daarna werkt `python3.11 -c "import mgba.core"`).
