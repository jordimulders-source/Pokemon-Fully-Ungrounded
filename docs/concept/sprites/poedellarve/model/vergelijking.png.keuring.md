# Keuring vergelijking.png (modelvarianten, geen sprite)
Dit is geen sprite maar een keuzevel: het model van Jordi naast twee kortere versies. Gemeten en bekeken op volle grootte en op ±1×.
- Kop, voelsprieten, ogen, neus, mond, voorlijf, voorpootjes (x ≥ 500): lijkt op het origineel; pixeldiff 0 (gemeten, beide varianten).
- Pluisbolletjes bovenop en ronde pootjes onder het achterlijf: lijkt op het origineel; onvervormd teruggeplakt, alleen verschoven.
- Achterlijfsegmenten: wijkt af in breedte (bewust, dat is de vraag): 75% resp. 65%; segmentlijnen staan dichter op elkaar. Bij 65% wordt het uiterste staartpuntje smal.
- Naden: geen zichtbare naden op volle grootte of 1×.
