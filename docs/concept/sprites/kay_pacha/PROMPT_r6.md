# Gemini-prompt Kay Pacha r6 (nieuw gesprek, bijlage = gemini/r3.png)

Jordi: "als deze een masker krijgt en de versieringen die hij heeft wat simplistischer zijn dan is dat een prima design".
Eigen invulling van Claude: masker van Inca-goud met zichtbare paarse ogen; "simpler" uitgelegd als: zelfde stukken, zonder gravures/spiralen/gezichten/kleine patronen.

```
This is a Grass/Psychic legendary Pokémon design (Gen 3 front sprite style, Ruby/Sapphire/Emerald). Keep this design: same pose, same body, same colors, same pieces of decoration in the same places. Only two changes:
1) It wears an Inca-style gold mask on its face; the purple eyes stay visible.
2) Make all the existing decorations simpler: the same pieces, but plain bold gold shapes with simple shading, without engravings, spirals, faces, tiny patterns or small details, so it can become a clean 64x64 sprite.
Plain white background, no ground, no shadow, no effects.
```
