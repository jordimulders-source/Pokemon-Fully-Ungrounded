# Studie: complexe ontwerpen op 64×64 (20 nov, agent + Claude)
38 frontsprites bekeken (vogels, legendaries, manen). Kern:
- Fijn detail → 2–5 grote plukken/lobben (Staraptor-sikkel, Braviary ±5 plukken van 3–4 px, Entei/Pyroar 4–6 lobben). Nooit losse haren; fijn element ≥2 px met eigen lijn.
- Vleugel: 3–6 slagpennen als "vingers", dekveren één vlak met 1–2 schaduwbanden. Patronen max 1–2 grote motieven.
- 3–4 hoofdmassa's (kop, romp/buik, vleugel, staart). Kop 25–35% van de hoogte; oog 3–5 px; lange nekken kort/gebogen.
- Gespreide vleugels alleen als de vleugels het ontwerp zijn (Ho-Oh, Zapdos); vogels met een opvallende kop staan in rustpose met gevouwen vleugels (Mandibuzz, Honchkrow, Staraptor, Toucannon, Swellow, Xatu). Lange staart diagonaal rechtsonder.
- Kleur: 3–4 kleurgroepen met verschillende kleurTOON (niet alleen helderheid) + 1 accent. Dark-sprites nooit helemaal donker: een groot licht vlak tegen de kop (Honchkrow-bef). Donker = verzadigd (pruim/bordeaux/navy).
- Kale huid (Mandibuzz): één glad vlak, harde rand naar de veren. Krop: rond licht vlak met eigen schaduw. Klauwen: lichte nagel aan donkere teen.
Contactvellen: scratchpad (niet bewaard).
