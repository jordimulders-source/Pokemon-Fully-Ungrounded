# Ability-keuzes: iconische verborgen abilities naar slot 1/2

Opdracht van Jordi: iconische (verborgen) abilities mogen in slot 1 of 2, zodat de speler ze kan krijgen. Niets is generfd: de ability die plaatsmaakte, gaat naar het verborgen slot (dat alleen trainers hebben). Zo blijft de set abilities per soort gelijk en blijven alle trainerteams geldig.

Overgeslagen: Mega/Gmax/Primal/Totem-vormen, soorten met een `// Project Grounded`-keuze of een revisie van Jordi die het slot vastlegt (o.a. Sharpedo/Carvanha, Mightyena/Poochyena, Ninjask, Sigilyph, Cacturne, Feebas, Hariyama), en verborgen abilities die niet iconisch zijn (Rain Dish, Big Pecks, Run Away, Telepathy, Frisk e.d.).

Notatie: slot 1 / slot 2 / verborgen (oud → nieuw).
