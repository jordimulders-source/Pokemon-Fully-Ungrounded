# Gemini-bijsturing charlatan-Alakazam, v4 (10 nov)

Bijlage: `ronde3_kaarten.png`. Twee losse prompts (één wijziging per keer), elk in een nieuw gesprek of na elkaar.
Jordi over ronde 3: "uitstekend [...] misschien dat er nog 1 ding bij kan"; op de voorstellen: "doe een korte verbeterprompt voor 1 en 3" (1 achterovergekamd haar, 3 zwarte snor).

## 1: achterovergekamd haar
```
Keep this sprite exactly the same (pose, body, cards, tuxedo, bow tie, eyes, mustache shape, style). Change only one thing: the top of the head and the base of the ears become dark grey to black and smooth, like slicked-back hair combed straight back. It is part of its body, not real hair: no strands, no widow's peak, no pointed lock on the forehead.
```

## 3: zwarte snor
```
Keep this sprite exactly the same (pose, body, cards, tuxedo, bow tie, head, eyes, style). Change only one thing: the mustache becomes black, with the same shape and the same twirled tips.
```
